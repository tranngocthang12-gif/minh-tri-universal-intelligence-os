# MILINDAPAÑHA REASONING LAB v0.1 — 2026-10-04

**Status:** ACTIVE LATER-EXPLANATORY REASONING LAB
**Historical boundary:** Milindapañha is used to sharpen reasoning, not to overwrite the early-discourse evidence hierarchy.

## 1. Study question

Can Nāgasena's dialogue method help MINH TRI understand:
- how to dismantle false dilemmas;
- how to use analogies;
- how to preserve causal continuity without a permanent self;
- how to solve apparent textual contradictions;
- how to distinguish conventional designation from ontological reification?

Yes — as a **secondary reasoning comparator**.

## 2. Module A — name/person/chariot

### Mil 3.1.1
Problem:
If "Nāgasena" is only a designation, what is the person?

Method:
- decompose the apparent unit;
- test whether any single component is the named whole;
- show that ordinary designation functions without requiring an extra permanent essence.

Reasoning form:
**CONVENTIONAL DESIGNATION WITHOUT SUBSTANCE REIFICATION.**

Early-text back-check:
- SN 22 aggregate analysis;
- SN 22.22 conventional "person" as burden bearer;
- SN 22.59 de-appropriation;
- SN 22.85 anti-annihilation guard.

Learning rule:
The chariot simile is a useful explanatory model.
Do not treat it as if it alone defines the complete early Buddhist doctrine of personhood.

## 3. Module B — continuity: neither same nor another

### Mil 3.2.1
Question:
Is the one reborn the same person or another?

Nāgasena's answer:
neither simply the same nor simply another.

Analogical strategy:
- infant -> adult continuity;
- milk -> curd -> butter/ghee;
- causally linked stages without numerical sameness of an immutable substance.

Reasoning form:
**CAUSAL CONTINUITY WITHOUT IDENTITY-SUBSTANCE.**

Early-text back-check:
- MN 38 / MĀ 201 reject the same unchanged consciousness transmigrating;
- SN 12.12 replaces "who?" with conditionality;
- SN 12.38 / SĀ 359 link intention and renewed existence;
- DN 15 remains a harder consciousness/rebirth witness.

Learning rule:
Milindapañha can clarify the logic, but cannot by itself close the unresolved early-text rebirth mechanism.

## 4. Module C — classify questions before answering

### Mil 5.2.2
Problem:
If the Buddha held nothing back, why were some questions left unanswered?

Milindapañha introduces a question-classification strategy rather than treating silence as ignorance.

Reasoning form:
**QUESTION-TYPE CLASSIFICATION BEFORE RESPONSE.**

Early-text back-check:
- MN 63;
- MN 72;
- SN 44.10;
- existing MINH TRI modes: DIRECT / ANALYTICAL / COUNTER-QUESTION / REFRAME / SET-ASIDE.

Learning rule:
This later explicit taxonomy is useful as a formalization of an earlier dialogical behavior, but must not be retroactively assumed to be the exact historical Buddha's own metalanguage.

## 5. Module D — apparent textual contradiction

### Mil 5.3.10 and the dilemma sections
Typical structure:
1. cite two statements;
2. force an apparent contradiction;
3. distinguish context, intention, audience, function, or scope;
4. preserve both when the contradiction is only superficial.

Reasoning form:
**CONTEXTUAL CONTRADICTION RESOLUTION.**

Example lesson:
A statement that sounds self-praising may function pedagogically rather than arise from vanity.

Guard:
Do not abuse contextualization to erase a genuine contradiction.
MINH TRI must keep:
- RESOLVED;
- PARTIAL;
- UNRESOLVED
labels.

## 6. Module E — debate hygiene

### Mil 4.4
The text lists dispositions that corrupt discussion, including:
- attachment;
- anger;
- delusion;
- conceit;
- greed;
- laziness;
- one-sided thinking;
- ignorance.

Reasoning form:
**EPISTEMIC CHARACTER AFFECTS ARGUMENT QUALITY.**

Early-text back-check:
- AN 3.65;
- MN 95;
- Aṭṭhakavagga anti-debate identity material.

Learning rule:
Argument quality is not only formal logic.
Motivation, ego investment, and one-sidedness distort inquiry.

## 7. Module F — sati/memory as multi-functional

### Mil 3.7.1
Milindapañha enumerates multiple ways memory can arise.

Value:
Shows why `sati` cannot be flattened into one modern meditation slogan.

Guard:
The detailed sixteenfold list is a later explanatory taxonomy.
Use it to widen semantic sensitivity, not to claim that the early Nikāyas always mean all sixteen senses by `sati`.

## 8. Module G — path, lay practice, and conditions

### Mil 6.4.2
Question:
If laypeople can realize Dhamma, are ascetic observances pointless?

Reasoning move:
Distinguish:
- possibility of realization;
- training conditions;
- usefulness of a discipline;
rather than infer that if X is not absolutely necessary in every case, X is useless.

Reasoning form:
**NECESSARY / SUFFICIENT / SUPPORTIVE CONDITION DISTINCTION.**

This is useful for:
- jhāna/insight sequence debates;
- renunciation questions;
- training-method comparisons.

## 9. Module H — Nibbāna and causality

### Mil 6.2.5
Problem:
The path has causes/conditions, yet Nibbāna is said not to be a produced conditioned thing.

Reasoning move:
Distinguish:
- causes that lead to realization/access;
from
- causes that manufacture the object realized.

Reasoning form:
**PATH-CONDITION ≠ PRODUCED-OBJECT CONDITION.**

Guard:
This is later Theravāda explanatory philosophy.
Back-check:
- SN 43 terminology;
- early cessation/dispassion language;
- avoid importing later ontology as if explicitly settled in all early texts.

## 10. How this changes MINH TRI's answer model

Add five meta-questions before answering a hard Buddhist question:

1. Is the noun merely a conventional designation for a conditioned complex?
2. Does the dilemma falsely require "same" or "different"?
3. Are two canonical statements contradictory, or different in scope/context?
4. Is the proposed condition necessary, sufficient, supportive, or merely common?
5. Is the user asking for ontology when the source only establishes a practical/causal distinction?

## 12. Evaluation

For each Milinda dilemma:
- identify the exact logical form;
- predict Nāgasena's solution before reading it;
- compare;
- back-check with early discourse;
- mark:
  - EARLY_SUPPORTED;
  - EARLY_COMPATIBLE;
  - LATER_SYSTEMATIZATION;
  - CONFLICTS_WITH_EARLY_EVIDENCE;
  - UNRESOLVED.

This keeps Mi Tiên Vấn Đáp useful without letting it silently rewrite the early canon.
