# PHASE 4 — A13 — THE RAFT: USING THE PATH WITHOUT CLINGING TO THE PATH

Status: CHAT_TAUGHT / PARTIAL_SOURCE_AUDIT
Date: 2026-10-04

MN 22: the Dhamma is compared to a raft for crossing over, not for holding on. The traveler first builds, depends on, and actively uses the raft to reach the safe shore; only after crossing does he set it down. The same discourse also warns that Dhamma grasped wrongly is like a water-snake seized wrongly. CROSS_TEXT_SYNTHESIS: this rejects both premature abandonment of practice and later clinging to the means.

SN 43: the unconditioned is distinguished from paths leading to it. This fits the raft logic: path and goal are not identical.

Aṭṭhakavagga bounded lexical audit:
- Snp 4.3 contains diṭṭhi in a context of being entrenched in one's own view and nissito in a context of reliance.
- Snp 4.12 depicts disputants dwelling in their own views, making their own view into 'truth', and uses nissāya for reliance on what is seen, heard, precepts/vows, or cognized while disparaging others.
- Guardrail: the target is view-clinging, dependence, conceit, and dispute; do not reduce this to 'all views are false'.
- This closes only a bounded diṭṭhi/nissaya slice in Snp 4.3 and 4.12. The full lexical pass remains open.

MILINDAPANHA_DIALECTIC: later Milindapañha reasoning sharpens the means/goal distinction and helps stress-test how a concept or practice can be used functionally without being reified into identity.

Main conclusion: the Buddhist path is self-transcending. It must be used correctly and strongly enough to cross the flood, but its success culminates in non-clinging. 'Do not cling to Dhamma' does not mean abandon right view, ethics, concentration, or wisdom before they do their work.
