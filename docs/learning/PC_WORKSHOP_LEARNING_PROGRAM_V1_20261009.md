Date: 2026-10-09

## Intent and boundaries
Owner approves a distinct PC workshop learning track. Learn PC hardware, Windows, storage, BIOS/UEFI, networks, fault diagnosis and maintenance; read current evidence before making claims. This is an EDUCATION program, not permission to autonomously change the Owner PC.
Desktop Commander is the observation/practice interface; GitHub protected main remains the only canonical learning authority. Local Brain is an optional noncanonical read-only mirror and must not be described as written or learning autonomously.
Do not touch BIOS/UEFI, partition tables, encryption, firewall, registry, startup services, credentials, private user files, driver updates, disassembly or other destructive/privileged actions without a new narrow Owner instruction and safe rollback plan. No broad scanning and no secrets in GitHub.

## Learning sequence and gates
PC01 — Fundamentals and system inventory: CPU, motherboard, RAM, GPU, power, cooling, peripherals; identify what is directly observed vs unverified. Read-only inventory, no settings changes.
PC02 — Windows anatomy: process/service/startup concepts, privileges, Task Manager, logs, update lifecycle. Read-only checks.
PC03 — Storage: SSD/HDD, SMART, partitions, backup and filesystem; theory only for partition/encryption operations.
PC04 — BIOS/UEFI, boot, Secure Boot and recovery; read/teach only, no firmware writes.
PC05 — Networking: LAN/Wi-Fi, DNS, DHCP, routing, connectivity and private/public boundaries; non-invasive checks.
PC06 — Diagnosis: formulate symptom, plausible causes, discriminating tests, evidence and safe corrective alternatives. Never guess a repair.
PC07 — Maintenance: backup, cleanup, health monitoring, thermal, privacy, recovery procedures. Mutations separately gated.
PC08 — Transfer & recovery: unseen scenarios, independent critique, new-seat reconstruction and corrected misconceptions.

## Teaching and evidence contract
Each checkpoint records: lesson ID, concepts taught in Owner-friendly Vietnamese, source and read-only evidence, observation limitations, own-words explanation, a mistaken hypothesis and counterexample, exercise with withheld answer, source/evidence status, security precautions, current/next checkpoint, open audits, Local Brain mirror status.
Understand/remember != a test PASS. A question or model answer alone is NOT proof the Owner understood. Mark exercises UNTESTED until separately evaluated. Promote learned claims to durable current only via protected PR/CI and authorized review; retain correction/supersession.
No autonomous PC activity or timed background learning is authorized by this program.

### PC01 content
- CPU executes instructions; RAM holds actively used working data; persistent SSD/HDD survives power-off. Storage type and speed require evidence, not assumptions.
- Motherboard connects buses and devices; firmware initializes hardware, then bootloader/OS continues startup.
- PSU supplies regulated power; cooling transfers heat; abnormal temperatures/instability require measured evidence.
- Windows processes are currently executing instances, not necessarily startup programs. A process being present does not prove useful background learning.
- Desktop Commander is a transport/interface, not an independent cognitive Learning Engine.
