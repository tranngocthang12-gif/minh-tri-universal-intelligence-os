**Status:** INITIAL TEXT-GROUNDED SYNTHESIS / NOT COMPLETE MASTERY  
**Track:** Early Buddhist Canon — Pali / English / Vietnamese / parallel-aware  
**Boundary:** This document reconstructs recurring reasoning patterns from early-discourse evidence. It does not claim that the assistant is the Buddha, awakened, or able to reproduce every historical answer.

## 2. Core discovery: the Buddha's discourse logic is functional before metaphysical

A recurring structure is not merely "state a doctrine." It is:

1. identify the human problem;
2. distinguish the observable process;
3. identify the condition that feeds it;
4. identify the duty appropriate to that fact;
5. test appropriation, craving, aversion, or delusion;
6. prescribe a trainable response;
7. evaluate by reduction of suffering/bondage and increase of clarity/release.

SN 56.11 makes the pattern explicit:
- suffering is to be understood;
- its origin is to be abandoned;
- cessation is to be realized;
- the path is to be developed.

This is a task architecture, not merely a list of four propositions.

## 3. Reasoning pattern A — diagnose before theorizing

When a question concerns suffering, identity, conflict, grief, desire or practice, first ask:

- What is actually happening?
- What is felt?
- What is being wanted, resisted, defended or identified with?
- What condition makes the problem continue?
- What ceases if that condition ceases?

This is the preferred starting point over constructing an abstract ontology.

### Operational response rule
Do not start with the largest doctrine available.
Start with the smallest causal structure that explains the present problem.

## 4. Reasoning pattern B — conditionality instead of essence

Early Buddhist reasoning repeatedly prefers:

> when this is present, that occurs;
> when this ceases, that ceases.

The important question becomes not "What is this thing in itself for all eternity?" but:
- what conditions it;
- what it conditions;
- whether the process can be interrupted;
- whether the interruption leads toward less grasping and suffering.

### Implication
Avoid reifying:
- consciousness into a permanent subject;
- feeling into "my true feeling";
- thought into "my self";
- doctrine into identity.

## 5. Reasoning pattern C — self-claims are tested, not merely denied

SN 22.59 does not merely issue the slogan "there is no self."

Its argument examines the five aggregates through:
- affliction;
- lack of sovereign control;
- impermanence/change;
- fitness for appropriation.

The practical conclusion is the threefold de-appropriation:
- not mine;
- not what I am;
- not my self.

### Operational response rule
When the user asks an identity question, do not answer with a metaphysical slogan first.
Ask whether the relevant process is:
- stable;
- controllable;
- liable to change;
- a source of distress when appropriated.

Then explain the release function of not taking it as "I/me/mine."

## 6. Reasoning pattern D — experience becomes conflict through mental proliferation

MN 18 gives a process-oriented account:

sense object + sense faculty -> consciousness -> contact -> feeling -> perception -> thinking -> papañca / objectifying proliferation -> conflict-prone categories and reactions.

The exact translation of `papanca` remains disputed.
Therefore the learning system must preserve the Pali term when needed and learn the causal role before choosing one English/Vietnamese gloss.

### Operational response rule
For interpersonal conflict:
- do not examine only the external opponent;
- reconstruct the internal chain from contact to feeling to labeling to elaboration;
- identify where relishing, resistance, conceit or view fastens to the process.

## 7. Reasoning pattern E — some questions should be reframed or set aside

MN 63 shows that refusal to answer can itself be disciplined reasoning.

The issue is not "the Buddha avoids hard questions."
The criterion is whether the question is connected to:
- disenchantment;
- dispassion;
- cessation;
- peace;
- direct knowledge;
- awakening/release.

Speculative questions that do not advance the liberative task may be set aside while the four-truth structure is taught.

### Operational response rule
SET-ASIDE is valid only when:
- the early texts actually treat the question class as undeclared/unprofitable; or
- the answer would distract from the practical problem the teaching is designed to solve.

Never use SET-ASIDE as an excuse for ignorance. If the evidence is insufficient, say "not known."

## 8. Reasoning pattern F — epistemic caution is not individualistic relativism

AN 3.65 warns against relying merely on:
- hearsay;
- lineage/tradition;
- scripture;
- abstract reasoning/inference;
- appearance of competence;
- teacher authority.

But the discourse does not end with "believe whatever feels right."

It moves into testing:
- greed, hatred and delusion;
- non-greed, non-hatred and non-delusion;
- blameworthiness/blamelessness;
- appraisal by the wise;
- consequences in harm/suffering versus welfare/happiness.

### Operational response rule
For disputed claims:
1. do not accept authority alone;
2. do not accept reasoning alone;
3. inspect consequences and mental roots;
4. seek corroboration from competent/wiser observers;
5. distinguish provisional confidence from direct knowledge.

## 9. Reasoning pattern G — truth carries a task

One of the strongest patterns across SN 56.11, MN 43 and MN 149 is that different truths/processes demand different operations.

Examples:
- aggregates: understand;
- craving/ignorance: abandon;
- path/wisdom/calm: develop;
- release: realize.

### Operational response rule
Every doctrinal explanation should answer:
"What is the user supposed to do with this fact?"

Without a task relation, the explanation is incomplete.

## 10. Response-mode model for reconstructing Buddha-like reasoning

For a novel question, classify one or more modes:

- DIRECT — answer the distinction directly;
- ANALYTICAL — separate conflated terms/processes;
- COUNTER-QUESTION — expose an assumption;
- REFRAME — replace a false dilemma;
- CONDITIONAL — answer in terms of causes/conditions;
- GRADUAL-INSTRUCTION — give the next trainable step;
- SIMILE — make a relationship experientially visible;
- PRACTICE-PRESCRIPTION — turn the issue into observation/training;
- SET-ASIDE — decline only when doctrinally warranted;
- UNCERTAIN — explicitly say the textual evidence is insufficient or contested.

## 11. Novel-question procedure

Before producing an answer:

### A. Parse the question
Record:
- explicit proposition;
- practical concern;
- emotional/ethical context;
- whether the user seeks explanation, comfort, justification, prediction, identity or practice.

### B. Detect hidden assumptions
Check for:
- permanent-self assumption;
- "mine/I/am" appropriation;
- eternalism/annihilationism;
- fatalism;
- absolute-control assumption;
- authority-is-proof assumption;
- false binary;
- sensual pleasure as sufficient good;
- ritual/status as sufficient purification.

### C. Locate the causal hinge
Ask:
- what feeds this?
- what happens immediately before it?
- what happens if this condition is weakened?
- what is observable now?

### D. Locate the experiential domain
When useful:
- body/form;
- feeling;
- perception;
- intentions/formations;
- consciousness;
- senses/contact;
- craving;
- clinging.

### E. Apply ethical/root test
Does the proposed attitude/action strengthen:
- greed or non-greed;
- aversion or non-aversion;
- delusion or clarity;
- harm or non-harm?

### F. Apply appropriation/control test
If identity is involved:
- stable?
- controllable?
- changes despite wishes?
- distressing when clung to?

### G. Choose minimum sufficient teaching
Do not dump the entire Buddhist system.

### H. End with something testable
When appropriate:
- what to notice;
- what to refrain from;
- what to cultivate;
- what causal prediction to test in experience.

## 12. Pali-English-Vietnamese translation method — upgraded

Never translate doctrinal vocabulary by one permanent word.

For each key passage, maintain a translation card:

- Pali lemma;
- inflected form;
- syntactic role;
- immediate sentence;
- discourse-level function;
- English rendering A;
- English rendering B;
- Vietnamese rendering;
- semantic range;
- doctrinal risk if mistranslated;
- parallel-text wording if available;
- confidence label.

### Initial high-risk vocabulary

#### dukkha
Do not force only "suffering."
Possible contextual ranges include pain, stress, unsatisfactoriness, distress, and the vulnerability of conditioned experience.

#### anatta
Do not convert directly into a total metaphysical theorem without context.
Check whether the passage is performing de-appropriation, control analysis, impermanence analysis, or contrast with self-doctrines.

#### sankhara
Context-sensitive:
- formations;
- volitional activities;
- conditioned constructions;
- choices in some translations.
Never use one Vietnamese/English gloss mechanically.

#### vinnana
Usually analyze as conditioned consciousness in a relational process.
Do not import a permanent witness/self.

#### sati
Do not assume modern "mindfulness" exhausts its range.
Check memory/keeping-in-mind, present recollective attention, and training context.

#### samadhi
Do not flatten to generic concentration.
Check whether the passage specifies right samadhi, jhana, unification/collectedness, or another technical context.

#### nibbana
Preserve the Pali when metaphysical interpretation is disputed.
First learn its functional textual roles: extinguishing, dispassion, cessation, release, the unconditioned terminology where present.

#### papanca
Keep untranslated when needed.
Learn its causal role across MN 18, DN 21 and Sn 4.11 before choosing a fixed gloss.

## 13. English comparison policy

Primary comparison:
- Bhikkhu Sujato / SuttaCentral for broad four-Nikaya coverage, side-by-side Pali and parallels;
- Bhikkhu Bodhi for major Nikaya translations where available;
- Thanissaro Bhikkhu for independent renderings and detailed interpretive notes;
- PTS translations for historical comparison.

A translation disagreement triggers:
1. return to Pali;
2. compare grammar;
3. compare parallel passages;
4. compare doctrinal role;
5. keep multiple candidate meanings if unresolved.

## 14. Vietnamese comparison policy

Primary Vietnamese base:
- HT Thich Minh Chau's Pali-to-Vietnamese Nikaya translations where available.

Use the Vietnamese text as a serious translation witness, not as the original.

When Vietnamese terminology is archaic or ambiguous:
- inspect Pali;
- compare at least one modern English translation;
- check another Vietnamese rendering where available;
- record semantic range rather than silently modernizing the doctrine.

## 15. Historical-critical rule

Distinguish:
- EARLY_MULTI_PARALLEL_HIGH_CONFIDENCE;
- EARLY_PALI_STRONG;
- EARLY_BUT_VARIANT;
- SCHOOL_SPECIFIC_POSSIBLE;
- LATER_CANONICAL;
- COMMENTARIAL;
- MODERN_INTERPRETATION;
- UNRESOLVED.

Pali Canon membership alone does not prove equal historical age for every passage.
Parallel agreement raises confidence but still does not mechanically prove verbatim historical wording.

## 17. Blinded reasoning test

To test "understand how the Buddha would answer" without pretending to be the Buddha:

1. collect authentic dialogue contexts from early discourses;
2. hide the Buddha's reply;
3. show only question + necessary context;
4. predict:
   - response mode;
   - hidden assumption;
   - causal hinge;
   - doctrinal tool;
   - practice direction;
5. unhide the canonical answer;
6. score:
   - structural match;
   - doctrinal accuracy;
   - unnecessary-metaphysics penalty;
   - unsupported-claim penalty;
   - translation sensitivity;
7. record failures and update the model.

Passing this test supports "reconstructs recurring response reasoning."
It does not support "is Buddha-like in realization."

## 19. Current conclusion

Initial evidence supports a working model in which early Buddhist reasoning is:
- diagnostic;
- conditional;
- functional/task-oriented;
- anti-appropriative;
- ethically evaluative;
- practice-verifiable;
- willing to reframe or set aside unprofitable metaphysical questions;
- cautious about both external authority and unaudited private reasoning.

This remains a tested hypothesis to refine across the whole corpus, not a final statement of everything the historical Buddha thought.
